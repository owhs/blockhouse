The dialog lists "Strongman Lifts — strongmanlifts.co.uk" with the current one marked "You are here" and not clickable; others link to `studioUrl + '/admin/'`. 3. **F4 one preview path, desktop means desktop**: Desktop = **1280px** virtual width, always through the same `fitForDevice` path on every document (find why automatic `d-about` bypasses it — likely a doc with `template`/`bare` or the device pref `''` vs undefined — and fix), scaled to fit the holder, unscaled only when the holder ≥ 1280. 4. **F5 collapsed rail names**: the icon rail (`side-collapsed`) shows each item as icon **with a small label underneath** (two-line, ~64px wide, 10.5px text, ellipsis), not hover-only. Section titles become thin dividers. Tooltips keep the hint; `aria-label` is the item name. Apply everywhere the rail is collapsed, not only in the editor.
5. **F6 page template options**: label each template option in the Page tab from its file name: `home` → "Home page", `product` → "Product page", `404` → "Not-found page", `list` → "List page", `range` → "Range page", `faqs` → "FAQs page", `page` → "Standard page", `project` → "Project page"; generic rule: capitalise, replace dashes, append " page"; the empty value reads "Default for {Type} ({derived label})". 6. **F10**: the block picker restores focus to the control that opened it (Add block button, tree row, or toolbar) on close/Escape.
7. **F11 outline rows**: two-line rows — line 1 the content preview (ellipsis), line 2 the block type in muted small text; when the label equals the type, one line. Keep row height compact (~2.3rem).
8. **F13 settings search landing**: after `goGroup(g, fieldKey)`, scroll the field into view centred and flash it without relying solely on `requestAnimationFrame` (use a `setTimeout(…, 0)` plus a `scrollIntoView` retry after the group's async sections resolve), and move focus to the field's input.
